# Airline Data Analysis Project

This project analyzes airline booking and flight data using SQL and Python.

## Objective

The goal is to identify opportunities to improve flight occupancy and increase revenue.

## Tools Used

- Python
- SQL
- SQLite
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Main Analysis

- Database exploration
- Data quality checks
- Booking and revenue trends
- Fare condition analysis
- Aircraft revenue analysis
- Occupancy rate analysis
- 10% occupancy improvement simulation

## Key Insight

Reducing empty seats can help the airline increase revenue without immediately adding new flights or aircraft.
